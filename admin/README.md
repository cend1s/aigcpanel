# 管理后台

基于 [Refine](https://refine.dev)（MIT）+ Ant Design 5 的管理后台，所有数据都通过后端 `/api/admin/*` 接口读写，
调额、补单、改模型等操作都会经过后端的业务逻辑（写额度流水、审计日志），不直连数据库。

## 开发与构建

```bash
cd admin
npm install
npm run dev      # http://localhost:5180/admin/ ，/api 代理到 http://127.0.0.1:3100（可用 API_TARGET 修改）
npm run build    # 产物在 admin/dist，后端启动时自动挂载到 /admin/
```

后端通过 `ADMIN_DIR`（默认 `../admin/dist`）找到构建产物。部署时只需先构建本目录，再启动后端，访问 `https://你的域名/admin/`。

首个管理员用后端脚本创建：

```bash
cd backend && npx tsx scripts/create-admin.ts admin@example.com '强密码'
```

## 功能

| 菜单 | 能做什么 |
|---|---|
| 概览 | 用户数、今日新增、今日收入、今日云端任务与失败数、今日消耗额度、近 7 天收入 |
| 用户 | 搜索；调额（必须填写原因，写入审计）；查看额度流水；禁用/启用（禁用会立即吊销该用户所有登录） |
| 订单 | 按订单号/邮箱/状态筛选；待支付订单可“人工补单”（核实收款后使用，幂等） |
| 兑换码 | 批量生成（数量、额度、批次、过期日期），生成后可一键复制 |
| 套餐 | 新建/编辑：价格（元）、有效天数、额度、功能权限 JSON、上下架、排序 |
| 云端模型 | 新建/编辑：名称必须以 `Cloud` 开头；供应商从后端已注册的适配器中选择；密钥只显示脱敏值，不改就保留原值 |
| 云端任务 | 按状态/用户/模型查看预扣、实扣、错误信息 |
| 审计日志 | 所有管理操作的记录（不含密钥） |

## 设计取舍

- **不提供删除**：套餐、模型等有财务含义的数据用“下架/停用”代替，避免历史订单和流水失去关联。
- **字段转换在数据层完成**（`src/providers.ts`）：后端存“分”和 JSON 对象，表单里显示“元”和 JSON 文本。
- **依赖安全**：`@refinedev/antd` 依赖的 `@ant-design/pro-layout` 锁定了有 ReDoS 漏洞的 `path-to-regexp@8.2.0`，
  在 `package.json` 的 `overrides` 中覆盖为同主版本修复版 8.4.2；当前 `npm audit` 为 0。
- 构建产物单包约 1.7MB（gzip 约 550KB），内部后台可接受，暂不做代码分割。
